# WordCardsMVP — веб-версия (PWA)

Полный порт `WordCardsMVP` (SwiftUI/SwiftData) в статичный веб-app без сборки —
чистый HTML/CSS/JS (ES-модули), без npm/фреймворков. Дизайн, цвета, шрифты
(`ui-rounded` / `-apple-system` — та же SF Rounded/SF Pro, что и в SwiftUI на iOS),
вся бизнес-логика интервалов повторения и все взаимодействия перенесены 1:1
из `WordCardsMVP/*.swift`.

## Локальный запуск

Нужен любой статический HTTP-сервер (просто открыть `index.html` файлом не
подойдёт — ES-модули и `fetch()` подборок требуют http/https).

```bash
cd web
python3 -m http.server 8080
```

Открыть `http://localhost:8080` в браузере.

## Данные

Хранятся в `localStorage` браузера одним JSON-блобом (аналог единственной
записи `PersistedStateRecord` в SwiftData). При первом запуске подгружаются
встроенные подборки из `web/data/*.csv` (те же файлы, что зашиты в iOS-бандл).

## Деплой на GitHub Pages

1. Запушить ветку/смержить в `main`.
2. В настройках репозитория: Settings → Pages → Source: Deploy from a branch,
   выбрать ветку и папку `/web` (или через GitHub Actions, если нужна папка
   `/` в отдельном репо/ветке gh-pages).
3. После публикации откроется `https://<user>.github.io/<repo>/`.

## Добавление на экран домой (iPhone)

1. Открыть опубликованный адрес в Safari.
2. Кнопка «Поделиться» → «На экран домой».

Дальше приложение открывается со своей иконкой в полноэкранном режиме без
адресной строки Safari и работает офлайн (service worker кэширует шелл
приложения и встроенные подборки).

## Известные ограничения по сравнению с iOS-версией

- Иконки экранов — не точная копия SF Symbols, а близкие по смыслу SVG
  (в вебе нет доступа к системному набору SF Symbols).
- Иконка приложения (`icons/icon-*.png`) сгенерирована с нуля в палитре
  приложения — в исходном Xcode-проекте не было реального `AppIcon`
  (`Assets.xcassets/AppIcon.appiconset` содержал только пустой конфиг).
- Long-press на карточке коллекции/слова (контекстное меню «Удалить» в
  SwiftUI) заменён на удержание ~0.5с либо правый клик — открывает то же
  подтверждение удаления.
- Даты (`Next review`, подписи графиков) форматируются через
  `toLocaleDateString` браузера — используют локаль устройства, как и
  `.formatted()` в Swift.
